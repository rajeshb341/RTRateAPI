HO6-08  Minimum Earned Premium is 0 in the Rater (lookup never matches) => Rater Related Issue
----------------------------------------------------------------------
Defect          : Rater (C226 / Rate Tables IX:JA)
Cases           : all 2,725 HO6 cases; Base Premium (C228) differs in 2,627 of them
Bug Summary     : The HO6 rows of the Minimum Earned Premium table hold the territory number as text ('1', '2' ...),
                  but C226 compares it with VALUE(MID(RatingTerritory,3,10)), a number, so no row matches and IFERROR
                  returns 0. The API returns the table value (300 / 350 / 500 / 750 / 1,000). Base Premium =
                  MAX(premium, Minimum Earned Premium) therefore differs whenever the premium is below the minimum.
Expected Result : 6585 (SC8): Minimum Earned Premium 500 (table HO6 / SC / 8), Base Premium 500 (as the API)
Actual Result   : Rater: Minimum Earned Premium 0, Base Premium 344
Evidence        : 6585 (HO6, HORRY SC, territory SC8)
Result path     : ...\HO6AndBugTCs\iterations\6585

--------------------------

6600: 504.8), which gives negative or very large premiums (6584 Final Property Premium -5,610.88 / -6,496.54).
The Misc Surcharge differences (C160, 296 cases) are those premium differences multiplied by such factors.
