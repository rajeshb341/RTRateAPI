========================================================================================================================
Severity        : High
Category        : Rater
Bug Summary     :
                  Rating Territory (C106) ignores the Zip code - the Rater takes the LAST county row of the territory
                  table, giving the wrong territory for split counties.

                  C106 = the territory of the row matching State + County + Zip, or the county "ALL" row when the zip
