Assumptions · edited

Every timing below is an estimate, not a measured value. Change any yellow field and the whole report recalculates. Replace these with your team's real timings before sharing figures.

Coverage areaManual navigate / open (min per TC)Manual template compare (min per form) Automation report review (min per TC)Failure rate (%)Manual analysis (min per failure)Automation analysis (min per failure)

How it is calculated. Manual execution for View Forms, Schedule of Forms and UI PDFs = navigate time + forms × 3 attributes × seconds per check. Issuance PDF = open time + forms × template-compare minutes per form. Failure analysis = failed TCs × analysis minutes (manual: find the mismatch, screenshot, compare, log the defect; automation: read the mismatch report, confirm, log the defect). Automation execution = report review per TC + run setup per cycle, split across the four areas. Unattended machine run time is shown separately and is not counted as effort. One-time script development and maintenance are excluded.
