BUG-02  Renewal: NonWindFDR is calculated from the unrounded non-wind premium, so every renewal premium is off by 1-4 cents
------------------------------------------------------------------------------
Issue Type      : API issue
Bug Summary     : The Rater calculates the New Business Non-Wind FDR as C229 = ROUND(C153 / (C108/100), 6) with C153 (Final Non-Wind Property Premium) rounded to 2 decimals. The API returns a NonWindFDR that differs in the 6th decimal (it is calculated from the unrounded premium). The renewal floor / ceiling (FDR x 1.5 / 1.7) and the renewal premium (FDR x TIV / 100) multiply the difference.
Expected Result : NonWindFDR = ROUND(ROUND(non-wind premium, 2) / (TIV/100), 6) as the Rater; renewal premiums equal to the Rater (C281, C288, C322) within 0.01.
Actual Result   : NonWindFDR differs by 0.000001 - 0.000005; renewal Non-Wind Premium, Calculated / Final Property Premium differ by 0.01 - 0.04.
