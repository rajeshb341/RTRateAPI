BUG-03  Gross AAL source differs - the Rater uses RMSModeledPremium (C156 = C44), the API ignores RMSModeledPremium and uses its wind model
========================================================================================================================
Severity        : High
Category        : Rater / API
Bug Summary     :
                  Gross AAL source differs - the Rater uses RMSModeledPremium (C156 = C44), the API ignores
                  RMSModeledPremium and uses its wind model.
Expected Result :
                  One agreed source for Gross AAL (C156), so that the wind premium C157 = C155 x C156 can be
                  reproduced from the Rater.
Actual Result   :
                  Rater C156 GrossAal = C44 RMSModeledPremium (test data input). The API does not use
                  RMSModeledPremium: the wind sample request gave Gross AAL 1057.08 both without RMSModeledPremium and
                  with RMSModeledPremium = 500, and 330.76 when only the latitude / longitude changed (re-tested 28
                  Oct). Until this is aligned, the automation recalculates the Rater with the API's Gross AAL for
                  every wind case that returns one; in this run no case returned one (BUG-01). Business / BA to
                  confirm which side is correct.
Evidence        : wind sample "HO3 WindCoverage Request.json" sent to the API on 28 Oct 2026:
                    as given (no RMSModeledPremium)          -> GrossAal 1057.08, WindAalFactor 5.25, Wind Premium 5549.65
                    RMSModeledPremium = 500                  -> GrossAal 1057.08, Wind Premium 5549.65 (unchanged)
                    Latitude / Longitude of Hampton, VA      -> GrossAal 330.76,  Wind Premium 1736.51
                    no Latitude / Longitude / Address        -> no GrossAal,      Wind Premium 0.0
