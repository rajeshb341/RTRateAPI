Hours by effort area

Area 1

Test coverage effort

Designing valid input combinations (state/county, subline/occupancy, valuation pairs, deductibles a configuration rates) and turning each one into an API request.

Manual coverage in practice

  • Each combination is hand-picked from 65 dropdowns and fields, with dependencies checked by eye.
  • Rater wording must be translated to API values (value mapping, range rows, distance-to-coast bands).
  • Realistic teams sample a few hundred cases; 6,000 is rarely reached.

Automated coverage achieved

  • 6,526 combinations in the test data, 6,422 executed.
  • 552,396 attribute checks, every one of 86 outputs on every case.
  • 14 states, 5 configurations exercised; invalid combinations auto-skipped (104).
  • Requests built from per-configuration templates and mapping files.
